# CodeAlpha Data Visualization Project

## Project Overview
This project is part of the CodeAlpha Data Analytics Internship.

The objective of this project is to analyze and visualize sales data using Python libraries like Pandas, Matplotlib, and Seaborn.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
- Sales by Category
- Profit by Category
- Correlation Heatmap
- Monthly Sales Trend

## Dataset
Superstore Sales Dataset

## Project Insights
- Technology category generated the highest sales.
- Profit varies across categories.
- Discount impacts profit negatively.
- Monthly sales trends help identify business growth patterns.
